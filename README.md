# data-cleaning-project
Cleaning and standardising a messy customer dataset for analysis


## Problem
A customer dataset contained inconsistent names, phone numbers and addresses, missing values, and customers who should not be contacted. This made it unusable for outreach or analysis.

## What I did
- Cleaned last names, phone numbers and addresses so each follows one format
- Standardised Yes/No columns to Y/N
- Replaced missing values and "N/a" placeholders with empty values
- Removed customers who asked not to be contacted and those with no phone number
- Saved the cleaned data to a new CSV file
